## Features

- Organize RSS feeds in one place
- Get personalized recommendations with a Python engine
- Enjoy a clean dark-mode reading experience
- Track reading streaks, XP, and badges

## Get Started

```bash
git clone https://github.com/korayozkan/NewRssFeed.git
cd NewRssFeed
npm install
npx expo start
```
