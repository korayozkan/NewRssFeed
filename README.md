## What is NewRssFeed?

NewRssFeed is a lightweight RSS reader that brings your favorite websites and news feeds together in one place, making it easier to follow the content you care about.


<p align="center">
  <img src="docs/images/dashboard.png" alt="NewRssFeed Dashboard" width="800" />
</p>

## Features

- Organize RSS feeds in one place
- Enjoy a clean reading experience
- Use a comfortable dark theme
- Browse with a lightweight interface


## Get Started

```bash
git clone https://github.com/korayozkan/RSS-Okuyucu.git
cd RSS-Okuyucu
python -m http.server 8080
```

Open `http://localhost:8080` in your browser.
